# ShopSmart - E-Commerce Website

## About the Project
ShopSmart is a responsive e-commerce website developed as part of the ApexPlanet Software Internship Task 5. It allows users to browse products, search for items, filter by category, sort products, and manage a shopping cart.

## Features
- Responsive website design
- Product listing with prices and ratings
- Search products by name or category
- Filter products by category
- Sort products by price and rating
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove items from the cart
- Automatically calculate the total price
- Save cart items using Local Storage
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Git and GitHub

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.
4. Browse products, use search and category filters, sort products, and test the shopping cart.

## Testing
The website should be tested for:
- Product display and image loading
- Search, category filtering, and sorting
- Cart functionality and total calculation
- Cart persistence after refreshing the page
- Responsive layout on mobile and desktop
- Browser compatibility

## Project Objective
The objective is to integrate HTML, CSS, and JavaScript skills to build a complete web application and improve its responsiveness, functionality, and compatibility.
